# Beispiel-Seeds (Deutsch)

MiroFish baut aus einem hochgeladenen „Seed"-Dokument eine parallele digitale Welt
und simuliert, wie tausende Agenten darauf reagieren. Ein guter Seed ist ein
zusammenhängender Text mit echten Akteuren, Fakten und einem Auslöser – z. B. eine
Nachricht, ein Gesetzentwurf, ein Marktbericht oder eine Ankündigung.

Dieser Ordner enthält drei einsatzbereite deutsche Beispiel-Seeds für den deutschen
Markt. Jede Datei beginnt mit einem Block **„Vorgeschlagener Simulations-Prompt"** –
genau das, was ihr beim Start im Feld *Simulations-Prompt* eintragen könnt.

## So nutzt du sie

1. MiroFish starten (`npm run dev` → http://localhost:3000).
2. Eine der `.md`-Dateien aus diesem Ordner hochladen (Drag & Drop im Bereich *Realitäts-Seed*).
3. Den vorgeschlagenen Prompt aus der Datei in das Feld *Simulations-Prompt* kopieren (oder einen eigenen formulieren).
4. **Engine starten**. Für den ersten Durchlauf den *Benutzerdefinierten Modus* mit wenigen Runden (z. B. 20–40) wählen, um Kosten und Fehlerrisiko gering zu halten.

## Übersicht

| Datei | Szenario | Anwendungsfall |
|-------|----------|----------------|
| `produktlaunch-elektro-kleinwagen.md` | Markteinführung eines bezahlbaren E-Kleinwagens | Produkt-/Markteinführung, Konsumentenstimmung |
| `gesetzentwurf-heizungsfoerderung.md` | Neuer Förder-Gesetzentwurf für Heizungstausch | Politik-/Policy-Prognose, öffentliche Debatte |
| `lokaler-einzelhandel-innenstadt.md` | Verkehrsberuhigung einer Innenstadt | Lokaler Markt, Einzelhandel, Bürgerstimmung |

> Hinweis: Die Inhalte sind frei erfundene, plausible Beispielszenarien zu
> Demonstrationszwecken. Namen, Zahlen und Ereignisse sind fiktiv.
